# VIOLEYE · EQUALITY LAB by Ana

Web inicial de consultoría y formación en igualdad de género.

## Publicación con GitHub Pages

1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda y espera a que GitHub Pages publique el sitio.

La web utiliza HTML y CSS estáticos y no necesita proceso de compilación. El logotipo vectorial está integrado en `index.html`.

## Antes de difundir

- Completar y revisar el directorio de cursos: fechas, plazas, requisitos y enlaces deben verificarse con cada entidad organizadora.
- Añadir aviso legal, política de privacidad y cookies si se incorporan formularios o analítica.
- El contacto actual abre el programa de correo del visitante; no almacena mensajes en una base de datos.
